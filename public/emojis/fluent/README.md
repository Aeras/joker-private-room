# Fluent Emoji — Flat SVG collection for JOKER

This folder contains 32 unmodified individual **Flat SVG** assets copied from
[microsoft/fluentui-emoji](https://github.com/microsoft/fluentui-emoji) (MIT License).
See [LICENSE](./LICENSE) for the required copyright and permission notice.

Assets are each a separate scalable SVG with transparent surrounding area.
They are **resources only**: no component, game UI, messaging behavior, or
emoji picker has been implemented or changed by this import.

For future UI work, render as `/emojis/fluent/grinning_face.svg` and similar names.
The source paths follow `assets/<Emoji name>/Flat/<emoji_slug>_flat.svg` in the upstream repo.
